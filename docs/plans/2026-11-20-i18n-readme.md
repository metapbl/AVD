# 서른 번째 계획 — 다국어 화면(F17)·README 6개 언어
Status: active | Started: 2026-11-20 | Source: PRD F17, §5 README 언어 (D082~D085) | 시작 커밋: eea53a5

Goal: 앱 화면이 English·한국어·简体中文·日本語·Español·Русский 로 보이고, 처음에는 OS 언어를 따르며(지원 밖이면 English), 환경설정에서 바꾸면 재시작 없이 바뀐다. GitHub README 도 같은 6개 언어로 있다.
Structure:
- 생김:
  - `utils/i18n.py` — `resolve_language(setting, locale_name) -> str`, `apply_language(app, code)`(앱 번역기와 `qtbase_*` 를 갈아 끼움), `LANGUAGES`(코드 → 그 언어로 쓴 이름)
  - `i18n/avd_{en,zh_CN,ja,es,ru}.ts`·`.qm` — 번역 원본과 컴파일본 (한국어는 원문이라 파일 없음)
  - `tools/update_translations.py` — 코드에서 문구를 모아 `.ts` 갱신(`pyside6-lupdate`) 후 `.qm` 생성(`pyside6-lrelease`)
  - `tests/test_i18n.py` — 언어 결정, 번역기 교체, 즉시 전환
  - `tests/test_translations.py` — 번역 완결성, 자리표시자 일치, `.qm` 최신, 감싸지 않은 한글 문구 없음
  - `README.{ko,zh-CN,ja,es,ru}.md`
- 바뀜:
  - `main.py` — `install_korean_translator` 대신 `apply_language`
  - `utils/config_manager.py > DEFAULT_CONFIG` — `ui_language`: "system"
  - `ui/*.py`, `models/download_item.py`, `core/`, `workers/`, `controllers/`, `utils/updater.py` 등 — 화면 문구를 `tr()`/`QCoreApplication.translate`/`QT_TRANSLATE_NOOP` 로 감싸고, 창마다 `retranslate()` + `changeEvent(LanguageChange)`
  - `ui/preferences_dialog.py` — "언어" 콤보
  - `AVD.spec` — `i18n/*.qm` 을 datas 에
  - `README.md` — 영어판으로 교체(지금 한국어 내용은 `README.ko.md` 로)
  - `AGENTS.md` 명령 — 번역 갱신 명령 한 줄
Global constraints:
- 원문은 지금 코드의 한글 문구 그대로 쓴다. 문구를 고치지 않는다 (기존 테스트가 한글 문구를 확인하므로, 번역기 없이 돌면 그대로 통과해야 한다)
- f-string 문구는 `tr("… {0} …").format(x)` 로 바꾼다. 자리표시자는 번역문에도 같은 개수·이름이어야 한다
- `self.tr` 은 PySide 에서 실행 중인 클래스 이름을 문맥으로 쓴다 — 상속되는 클래스 안에서는 `QCoreApplication.translate("클래스명", …)` 를 쓴다. QObject 밖(모델·core·워커가 만든 문구)은 `QCoreApplication.translate("문맥", …)`, 값으로 저장되는 상수는 `QT_TRANSLATE_NOOP` 로 표시하고 보일 때 번역한다
- `DownloadStatus` 값은 바꾸지 않는다(내부 비교에 쓰임). 보일 때만 번역한다
- 로그·예외 원문(yt-dlp "자세히")·파일명 기본값·docs 는 번역하지 않는다 (PRD F17 범위)
- 색은 `ui/theme.py` 이름으로 (D065). 워커→메인 연결은 QueuedConnection (D013). `gaindb/` 는 고치지 않는다 (D015)
- yt-dlp 핀은 올리지 않는다 (D002)
Test seam: `utils.i18n.apply_language(app, code)` 를 부른 뒤 열린 창·위젯의 보이는 문구
