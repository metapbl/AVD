Goal: 환경설정 창 높이를 지금 793~933px 에서 500px 이하로 줄인다. 왼쪽 목록(일반·다운로드·MP3 음량·로그인 쿠키)으로 오른쪽 페이지를 바꾸는 형태로 하되, 설정 항목·저장 방식·기존 동작은 그대로 둔다. 끝나면 v1.7.1 로 배포한다.
Structure:
- 바뀜: `ui/preferences_dialog.py`(배치만 — 그룹 상자는 그대로 페이지에 옮김), `i18n/*.ts`·`.qm`(목록 이름 새 문구), `CHANGELOG.md`, `utils/updater.py > APP_VERSION`
- 생김: 테스트(`tests/test_preferences_layout.py`), 태그 `v1.7.1`, Release `AVD v1.7.1`
Global constraints:
- 설정 키·저장(`_on_save`)·불러오기(`_load_values`)·위젯 속성 이름(`combo_language`, `_cookie_radios`, `chk_gain` 등)을 바꾸지 않는다 — 기존 테스트가 그대로 통과해야 한다
- 창 높이는 페이지 중 가장 긴 것에 맞춰 고정한다. 페이지를 바꾸거나 MP3 정규화·cookies.txt 를 켜고 꺼도 창 크기가 흔들리지 않게 한다(지금의 `adjustSize` 재조정은 페이지 안에서만)
- 색은 `ui/theme.py` 이름으로 (D065). 목록 선택 색은 테마의 `QAbstractItemView` 스타일을 쓴다
- 목록 이름은 번역한다(6개 언어). Enter 는 계속 "저장" (D060), 키보드만으로 목록 이동·페이지 안 이동이 된다
- README 스크린샷은 환경설정을 담지 않아 그대로 둔다 (D089)
Test seam: `PreferencesDialog` 를 만들고 목록에서 페이지를 고른 뒤의 보이는 위젯·창 크기
