  - Given README `## 실행`·`## 문서` 절 / When 읽는다 / Then config 위치는 "앱 폴더의 `config.json`", 루트 `CLAUDE.md`·`WORKLOG.md` 링크 없음 (`grep -n "CLAUDE.md\|WORKLOG.md" README.md` 결과가 존재하는 파일만 가리킴)
- 확인 방법: 자동 (grep·git diff)

### F11 [첫 계획 D, 맨 앞] venv 재생성·의존성 상향 (D027, D028)
- 인수 기준 (D029):
  - Given 깨진 `venv/` / When 설치된 Python 3.15.1(`py -3.15`) 로 재생성 후 `pip install -r requirements.txt` / Then 오류 없이 설치, `pip check` 통과

  - Given `requirements.txt` diff / When 본다 / Then 바뀐 줄은 정확히 `PySide6`·`PySide6_Addons`·`PySide6_Essentials`·`shiboken6` 6.11.1→6.12.0, `numpy` 2.5.1→2.5.4, `scipy` 1.18.0→1.18.1 뿐 (yt-dlp 등 불변)
  - Given README 요구 사항 / When 읽는다 / Then "Python 3.12 이상" 으로 표기
- 확인 방법: 자동(설치·pip check) + 실기(기동, 성공 기준 장면은 F10 마무리에서)

### F12 [다음 계획] Vimeo 공개 영상 (D067~D070)

  - Given 링크 `https://vimeo.com/22439234` / When 붙여 넣는다 / Then 화질 선택 창이 뜨고 받은 파일이 재생된다
  - Given `vimeo.com/1084537` 꼴 링크 / When 주소 바꾸기 함수 / Then `player.vimeo.com/video/1084537`. 해시가 붙은 링크·다른 사이트 링크는 그대로

### F13 [스물세 번째 계획] 최고 호환 영상 · M4A 음원 선택지 (D072~D074)
- 화질 선택 창과 플레이리스트 선택 창에 "최고 호환 (H.264 + AAC)"·"M4A 오디오" 를 더한다. 기존 선택지("최고 화질 (자동 선택)" 첫 줄·기본값, 해상도 행, MP3 192kbps + 음량 정규화)는 그대로 [U]
- 화질 선택 창 순서: 최고 화질 → 최고 호환 → MP3 → M4A → 해상도 행(높은 순). 2160p·4320p 행은 "4K 2160p MP4"·"8K 4320p MP4" 로 적는다 (D075) [U]
- 최고 화질·최고 호환 행에는 yt-dlp 가 고를 형식의 해상도·코덱·크기를 미리 적는다. 못 구하면 "자동" (D076) [U]
- 인수 기준:
  - Given 4K 가 있는 YouTube 영상 / When "최고 호환" 으로 받는다 / Then ffprobe 로 영상 `h264`·오디오 `aac` 인 mp4, 재생된다
  - Given 같은 영상 / When "최고 화질 (자동 선택)" 으로 받는다 / Then 전과 같다
  - Given 같은 영상 / When "M4A 오디오" 로 받는다 / Then `aac` 인 m4a, 썸네일 임베드·제목 태그가 있고 비트레이트가 원본 AAC 와 같다 (재인코딩 없음)
  - Given 같은 영상 / When "MP3" 로 받는다 / Then 192kbps + 음량 정규화 그대로
  - Given 원본이 AAC 가 아닌 사이트(SoundCloud 한 곡) / When "M4A 오디오" / Then AAC 로 변환되어 완료
  - Given 플레이리스트 / When 선택 창에서 "최고 호환"·"M4A" 를 각각 고른다 / Then 항목마다 그 형식으로 완료
  - Given 화질 선택 창에서 고정 행(최고 화질·최고 호환·MP3·M4A)을 골랐다 / When 다음 링크의 창이 열린다 / Then 같은 행이 선택돼 있다
- 확인 방법: 자동(행 구성·포맷 문자열 선택 결과·기억) + 실기(Windows, ffprobe). macOS 는 확인 안 함
