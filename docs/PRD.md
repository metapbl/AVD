- 해결할 문제: yt-dlp 의 영상·오디오 다운로드를 명령줄 없이 GUI 로 — 화질 선택, 동시 다운로드, 한글 파일명·태그 보존, MP3 음량 정규화까지 한 번에. [X] README
- 사용자 (누가, 몇 명, 어떤 기기): 개발자 본인(Windows 11 주 사용, macOS 실행), 그리고 GitHub 무료 공개로 받는 불특정 사용자. [X] CLAUDE §2, README (D012, D016)
- 성공 기준 (관찰 가능한 장면 하나): (미정 → OPEN)
- 기한과 수명 (언제까지, 다 쓰면 폐기/유지): 기한 없음, 계속 유지 [AI] (2026-05 부터 지속 개발 이력)
