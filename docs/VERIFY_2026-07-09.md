## 1. 썸네일 동시성 게이트 (fix `4fadbf6`)

**무엇을 고쳤나**: 플레이리스트를 한꺼번에 추가하면 리스트 미리보기 썸네일이
일부(약 25%) 안 뜨던 문제. 썸네일 다운로드를 한 번에 최대 4개로 제한하고,
실패 시 1.5초 뒤 1회 재시도하도록 바꿈.

### 1-A. 긴 플레이리스트 썸네일 전부 표시
- [ ] **40개 이상** 항목이 있는 유튜브 재생목록 URL 을 입력해 일괄 추가
- [ ] 모든 항목이 리스트에 추가된다
- [ ] 잠시 후 **모든 항목의 썸네일이 하나도 빠짐없이** 표시된다
      (예전엔 여기서 4~5개가 회색 빈칸으로 남았음)
- [ ] 스크롤을 위아래로 움직여도 빈 썸네일이 없다

### 1-B. 추가 직후 제거 (게이트 정리 확인)
- [ ] 위 플레이리스트를 추가하자마자, 썸네일이 아직 로딩 중인 상태에서
      임의 항목 몇 개를 **삭제(X)**
- [ ] 앱이 멈추거나 튕기지 않는다
- [ ] 남은 항목들의 썸네일은 계속 정상적으로 채워진다

### 1-C. 오프라인/네트워크 순단 (선택)
- [ ] 플레이리스트 추가 직후 잠깐 Wi-Fi 를 껐다가(2~3초) 다시 켠다
- [ ] 순단 때 실패했던 썸네일이 잠시 후 재시도로 채워지거나,
      끝내 안 되면 그냥 빈칸으로 남되 **앱은 정상 동작**한다 (무한 로딩·크래시 없음)

## 2. 다운로드 자동 재시도 (feat `47d347a` + fix `b22ff49`, ADR-007)

**무엇을 넣었나**: 다운로드가 일시적 오류(403 토큰 만료·429·5xx·타임아웃·
연결 끊김 등)로 실패하면, 새 세션으로 최대 3회까지 자동 재시도(2→5→10초 대기).
영구 오류(비공개·삭제·지역차단·존재하지 않는 영상 등)는 재시도 없이 즉시 실패.

### 2-A. 정상 다운로드 (회귀 — 기존 기능 안 깨졌나)
- [ ] 평범한 공개 영상 1개를 다운로드 → **정상 완료(DONE)**
- [ ] 진행률·속도·남은시간·파일크기 표시가 예전처럼 정상
- [ ] 저장 폴더에 파일이 실제로 생성됐고 재생된다

### 2-B. "재시도 중 (N/M)" 라벨 노출 (일시 오류 유발)
> 일시 오류를 인위적으로 만드는 가장 쉬운 방법: **다운로드 중 Wi-Fi 끊기**.

- [ ] 큰 영상(수백 MB) 다운로드를 시작
- [ ] 다운로드가 진행되는 도중 **Wi-Fi/랜을 끊는다**
- [ ] 항목 상태 라벨이 **"재시도 중 (1/3)"** → (2/3) → … 로 바뀐다 (주황색 글자)
- [ ] 몇 초 안에 **Wi-Fi 를 다시 켠다**
- [ ] 재시도가 성공해 다운로드가 이어지고 최종 **DONE** 이 된다

### 2-C. 재시도 소진 후 실패
- [ ] 위와 같이 시작한 뒤 **Wi-Fi 를 계속 꺼둔 채** 방치
- [ ] "재시도 중 (1/3)…(3/3)" 을 거쳐 최종 **ERROR** 상태가 된다
- [ ] 재시도 사이 대기(약 2초→5초→10초)가 눈에 보인다
- [ ] 이때 **수동 재시도 버튼**을 누르면(네트워크 복구 후) 다시 받아진다

### 2-D. 영구 오류는 재시도 안 함 (fix `b22ff49` 핵심)
- [ ] **존재하지 않는 영상** URL 을 넣고 다운로드
      (예: `https://www.youtube.com/watch?v=zzzzzzzzzzz`)
- [ ] "재시도 중" 라벨이 **뜨지 않고**, 곧바로 **ERROR** 로 끝난다
      (예전 오분류라면 여기서 헛되이 3번 재시도하며 시간을 끌었을 것)
- [ ] 비공개/삭제된 영상 URL 도 마찬가지로 즉시 ERROR

### 2-E. 재시도 대기 중 취소 반응성
- [ ] 2-C 처럼 재시도 대기(예: 10초 백오프)에 들어간 항목을 **취소(정지)**
- [ ] 10초를 다 기다리지 않고 **거의 즉시** CANCELLED 로 바뀐다
      (백오프 대기가 0.1초 단위로 취소를 확인하도록 만듦)
