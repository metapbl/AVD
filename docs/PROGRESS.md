- (정보) `default_format` 설정 키도 기본값만 있고 쓰이지 않음 (2026-11-11 확인)
- (정보) `language` 설정 키는 쓰지 않는다 — 화면 언어는 `ui_language`(D084). 예전 설정 파일의 `theme` 키는 무시된다 (D065) — 단서: `utils/config_manager.py > DEFAULT_CONFIG`
